# LaunchNG

**भाषाएँ**: [English](../README.md) | [简体中文](README.zh.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [हिन्दी](README.hi.md) | [Tiếng Việt](README.vi.md) | [Italiano](README.it.md) | [Čeština](README.cs.md)

macOS Tahoe (26) ने Launchpad को पूरी तरह हटा दिया। LaunchNG इसे एक नेटिव ऐप के रूप में वापस लाता है: पहली बार लॉन्च होने पर यह आपके मौजूदा Launchpad लेआउट को सीधे macOS के अपने डेटाबेस से पढ़ता है, फिर पेजिंग, फ़ोल्डर, खोज और ड्रैग-एंड-ड्रॉप रीऑर्डरिंग को एक Core Animation-रेंडर्ड ग्रिड पर फिर से लागू करता है — साथ में Dock एकीकरण, एक बंडल किया गया CLI/TUI, और ऐप के भीतर ही एक हस्ताक्षरित ऑटो-अपडेटर।

## डाउनलोड करें

**[नवीनतम रिलीज़ प्राप्त करें](https://github.com/moonmig/LaunchNG/releases/latest)**

अगर आपको यह उपयोगी लगे, तो रिपॉज़िटरी पर एक स्टार दें — इसकी सराहना की जाएगी। LaunchNG की शुरुआत RoversX के [LaunchNext](https://github.com/RoversX/LaunchNext) के फोर्क के रूप में हुई थी — मूल प्रोजेक्ट भी एक स्टार का हकदार है।

### अगर macOS ऐप को शुरू होने से रोकता है

रिलीज़ अहस्ताक्षरित/ad-hoc बिल्ड हैं (यह फोर्क किसी सशुल्क Apple Developer खाते का उपयोग नहीं करता), इसलिए Gatekeeper तब तक ऐप खोलने से इनकार करेगा जब तक आप एक बार क्वारंटीन फ्लैग नहीं हटा देते:

```bash
sudo xattr -r -d com.apple.quarantine /Applications/LaunchNG.app
```

यह कमांड केवल उन ऐप्स के लिए चलाएँ जिन पर आपको वास्तव में भरोसा है — यह उस ऐप के लिए macOS की डाउनलोड-क्वारंटीन जाँच को अक्षम कर देता है।

क्या आप सोर्स से बिल्ड कर रहे हैं? नीचे [लोकल कोड साइनिंग कॉन्फ़िगर करें](#configure-local-code-signing) देखें; आपको इस कमांड की आवश्यकता नहीं होगी।

## LaunchNG क्या करता है

- **असली Launchpad डेटाबेस से एक-क्लिक इम्पोर्ट** — सीधे `/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db` पढ़ता है और आपके मौजूदा फ़ोल्डर, पोज़िशन और पेजों को ठीक वैसे ही फिर से बनाता है
- **क्लासिक पेज्ड-ग्रिड अनुभव** — खोज, कीबोर्ड नेविगेशन, ड्रैग-एंड-ड्रॉप रीऑर्डरिंग, एक आइकन को दूसरे पर खींचकर फ़ोल्डर बनाना
- **पूरी तरह Core Animation रेंडरिंग**, जिसमें सीधे Dock में ड्रैग-एंड-ड्रॉप और macOS 26 पर नेटिव Liquid Glass फ़ोल्डर आइकन शामिल हैं
- **फ़ोल्डर लेआउट**: पेज्ड (मूल की तरह) या वर्टिकल स्क्रॉलिंग, आपकी पसंद के अनुसार
- **फ़ज़ी खोज** CJK (पिनयिन/रोमनीकरण) मिलान के साथ, ताकि आंशिक या अपूर्ण इनपुट भी सही ऐप ढूँढ सके
- **हॉट कॉर्नर और ट्रैकपैड जेस्चर एक्टिवेशन**, जिसमें प्रायोगिक 4/5-उंगली पिंच और टैप सपोर्ट शामिल है
- **एक CLI और TUI** ताकि आप टर्मिनल से अपना लेआउट देख या स्क्रिप्ट कर सकें
- **[Sparkle](https://sparkle-project.org) के ज़रिए हस्ताक्षरित स्वचालित अपडेट**, ऐप के भीतर एक सामान्य "अपडेट जाँचें" बटन के साथ
- **आपकी पसंद के फ़ोल्डर में लोकल बैकअप**, एक प्रबंधित इतिहास के साथ जिससे आप रीस्टोर कर सकते हैं
- **ऐप आइकन लेबल छिपाएँ, आइकन का आकार बदलें, स्पेसिंग समायोजित करें** — मुख्य ग्रिड और फ़ोल्डर सामग्री के लिए स्वतंत्र रूप से
- **13 भाषाओं** में पूर्ण UI अनुवाद (ऊपर भाषा सूची देखें)
- **बेहतर संदर्भ मेनू** — Finder में दिखाएँ, ऐप पाथ कॉपी करें, फ़ोल्डर का नाम बदलें, और (वैकल्पिक) अन्य भरोसेमंद ऐप्स के लिए Gatekeeper-अनब्लॉक शॉर्टकट
- **कंट्रोलर और वॉयस-फीडबैक सपोर्ट** एक्सेसिबिलिटी-केंद्रित सेटअप के लिए

## macOS Tahoe ने क्या छीना

- कोई उपयोगकर्ता-निर्मित फ़ोल्डर या कस्टम संगठन नहीं
- ड्रैग-एंड-ड्रॉप से पुनर्व्यवस्थित करने की सुविधा नहीं
- कोई विज़ुअल ऐप मैनेजमेंट ही नहीं — बस एक ऑटोमैटिक रूप से जनरेट किया गया, वर्णानुक्रम में सजाया गया ग्रिड जिसे आप छू भी नहीं सकते

LaunchNG इसलिए मौजूद है क्योंकि यह एक वास्तविक गिरावट है, कोई उचित डिफ़ॉल्ट नहीं।

## आपका डेटा कहाँ रहता है

LaunchNG का अपना लेआउट, प्राथमिकताएँ और कैश यहाँ रहते हैं:

```
~/Library/Application Support/LaunchNG/Data.store
```

कुछ भी कहीं नहीं भेजा जाता। एकमात्र नेटवर्क गतिविधि अपडेट फ़ीड की जाँच है, और जब आप चुनें, तो Apple के अपने Launchpad डेटाबेस को यहाँ से पढ़ना:

```bash
/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db
```

## इंस्टॉलेशन

### आवश्यकताएँ

- macOS 26 (Tahoe) या बाद का
- Apple Silicon या Intel
- Xcode 26, अगर सोर्स से बिल्ड कर रहे हैं

### सोर्स से बिल्ड करें

```bash
git clone https://github.com/moonmig/LaunchNG.git
cd LaunchNG
open LaunchNG.xcodeproj
```

<a name="configure-local-code-signing"></a>**लोकल कोड साइनिंग कॉन्फ़िगर करें** (किसी सशुल्क Apple Developer खाते की आवश्यकता नहीं):

- **LaunchNG** टारगेट चुनें → **Signing & Capabilities** → **Team** को `None` पर सेट करें, प्रमाणपत्र को `Sign to Run Locally` पर सेट करें। Hardened Runtime चालू रखें।
- इसके बाद Xcode प्रोजेक्ट फ़ाइल को संशोधित के रूप में चिह्नित कर देगा — पुल रिक्वेस्ट में केवल साइनिंग से जुड़े बदलाव शामिल न करें।

`⌘R` से चलाने के लिए, डेस्टिनेशन **My Mac** होना चाहिए — एक यूनिवर्सल/"Any Mac" डेस्टिनेशन बिल्ड और आर्काइव कर सकता है, लेकिन डीबगिंग के लिए लॉन्च नहीं हो सकता। केवल बिल्ड के लिए `⌘B`।

### कमांड-लाइन बिल्ड

```bash
xcodebuild -project LaunchNG.xcodeproj -scheme LaunchNG -configuration Release

# यूनिवर्सल बाइनरी (Apple Silicon + Intel):
xcodebuild -project LaunchNG.xcodeproj -scheme LaunchNG -configuration Release \
  ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO clean build
```

## इसका उपयोग कैसे करें

1. **पहली बार लॉन्च होने पर** आपके इंस्टॉल किए गए एप्लिकेशन अपने आप स्कैन हो जाते हैं।
2. **Settings → General → Import System Launchpad** एक क्लिक में आपका मौजूदा लेआउट, फ़ोल्डर और पोज़िशन ले आता है।
3. चुनने के लिए क्लिक करें, लॉन्च के लिए डबल-क्लिक (या Return) करें; खोजने के लिए कहीं भी टाइप करें।
4. एक ऐप को दूसरे पर खींचकर फ़ोल्डर बनाएँ; ऐप्स को खींचकर पुनर्व्यवस्थित करें।
5. यदि आप टर्मिनल से अपने लेआउट को स्क्रिप्ट करना चाहते हैं तो Settings में CLI को वैकल्पिक रूप से सक्षम करें।

### फुलस्क्रीन बनाम कॉम्पैक्ट

- **फुलस्क्रीन** पूरी स्क्रीन को कवर करता है, मूल Launchpad के सबसे करीब।
- **कॉम्पैक्ट** एक फ्लोटिंग, गोल-कोनों वाली विंडो है जिसका आकार आप बदल सकते हैं।
- दिखावट सेटिंग्स (आइकन स्केल, स्पेसिंग, पेज-इंडिकेटर पोज़िशन, और अधिक) प्रत्येक मोड के लिए अलग-अलग ट्रैक की जाती हैं।
- फुलस्क्रीन वैकल्पिक रूप से मेनू बार छिपा सकता है; जब यह चालू हो तो macOS अपने आप Dock भी छिपा देता है।

## उल्लेखनीय सेटिंग्स

- **दिखावट**: आइकन स्केल, लेबल आकार और दृश्यता, ग्रिड स्पेसिंग — फ़ोल्डर सामग्री के लिए अलग मानों के साथ — साथ ही एक बैकग्राउंड शैली (ब्लर, नेटिव Liquid Glass, या लाइव वॉलपेपर से प्राप्त बैकड्रॉप)
- **खोज**: फ़ज़ी मिलान टॉगल और खोज डिबाउंस समय
- **छिपे हुए ऐप्स**: बिना अनइंस्टॉल किए विशिष्ट ऐप्स को ग्रिड से बाहर रखें
- **बैकअप**: एक फ़ोल्डर चुनें, टाइमस्टैम्प वाले बैकअप बनाएँ, सूची से पुराने बैकअप रीस्टोर या डिलीट करें
- **शॉर्टकट और जेस्चर**: ग्लोबल हॉटकी, हॉट कॉर्नर, और (प्रायोगिक) ट्रैकपैड जेस्चर बाइंडिंग
- **अपडेट**: ऑटोमैटिक-चेक टॉगल और एक मैनुअल "अपडेट जाँचें" बटन, दोनों Sparkle द्वारा संचालित

## समस्या निवारण

**ऐप शुरू नहीं होता।** पुष्टि करें कि आप macOS 26.0 या बाद के संस्करण पर हैं और क्वारंटीन फ्लैग हटाया जा चुका है (ऊपर देखें)।

**"अपडेट जाँचें" कुछ गलत होने का संकेत देता है।** LaunchNG एक हस्ताक्षरित अपडेट फ़ीड के साथ Sparkle का उपयोग करता है; एक मैनुअल जाँच को हमेशा कुछ ही मिनटों में नवीनतम प्रकाशित रिलीज़ को दर्शाना चाहिए।

**टर्मिनल में `launchng` कमांड नहीं दिखता।** यह वैकल्पिक है — पहले Settings में कमांड लाइन इंटरफ़ेस सक्षम करें, और LaunchNG खुद प्रबंधित शिम इंस्टॉल कर देगा (और बाद में इसे हटा भी सकेगा)।

## योगदान करें

1. रिपॉज़िटरी को फोर्क करें
2. एक फीचर ब्रांच बनाएँ (`git checkout -b feature/your-feature`)
3. अपने बदलावों को एक स्पष्ट संदेश के साथ कमिट करें
4. ब्रांच को पुश करें और एक पुल रिक्वेस्ट खोलें

कुछ चीज़ें जो रिव्यू को सुचारू बनाने में मदद करती हैं:
- केवल साइनिंग से जुड़े Xcode प्रोजेक्ट बदलावों को अपने डिफ़ से बाहर रखें (ऊपर लोकल कोड साइनिंग देखें)
- अगर आप Core Animation ग्रिड को छू रहे हैं, तो पहले `GridReorderPlan.swift` देखें — रीऑर्डर/पेजिंग लॉजिक वहीं होना चाहिए, हर व्यू में दोहराया नहीं जाना चाहिए
- पुल रिक्वेस्ट खोलने से पहले टेस्ट सूट चलाएँ:
  ```bash
  xcodebuild test -scheme LaunchNG -destination 'platform=macOS'
  ```

ताज़ा, अद्यतन स्क्रीनशॉट (मुख्य ग्रिड, कुछ Settings टैब) भी वास्तव में उपयोगी योगदान हैं — इस फ़ाइल की शुरुआत के पास प्लेसहोल्डर देखें।

### अतिरिक्त दस्तावेज़ीकरण

- [Folder Liquid Glass](../Documentation/FolderLiquidGlass.md) — फ़ोल्डर ग्लास आइकनों के पीछे डिज़ाइन बाधाएँ, क्या सत्यापित है, और अभी क्या स्वीकृति परीक्षण की आवश्यकता है
- [Grid diagnostics](../scripts/diagnostics/README.md) — ग्रिड और ग्लास ओवरले के लिए मैनुअल प्रोब, उनके सटीक कवरेज और सीमाओं के साथ
