# LaunchNG

macOS Tahoe (26) убрала Launchpad полностью. LaunchNG возвращает его как нативное приложение: при первом запуске он читает вашу существующую раскладку Launchpad прямо из системной базы данных macOS, а затем самостоятельно реализует постраничную навигацию, папки, поиск и перетаскивание для изменения порядка — поверх сетки, отрисовываемой через Core Animation, с интеграцией с Dock, встроенными CLI/TUI и подписанным автообновлением прямо в приложении.

### Если macOS блокирует запуск приложения

Релизы собираются без подписи (ad-hoc) — этот форк не использует платный аккаунт разработчика Apple, — поэтому Gatekeeper откажется открывать приложение, пока вы один раз не снимете флаг карантина:

```bash
sudo xattr -r -d com.apple.quarantine /Applications/LaunchNG.app
```

Выполняйте эту команду только для приложений, которым доверяете, — она отключает проверку карантина загруженных файлов именно для этого приложения.

Собираете из исходников? Смотрите раздел [Настройка локальной подписи](#configure-local-code-signing) ниже — эта команда вам не понадобится.

## Что умеет LaunchNG

- **Импорт из реального Launchpad в один клик** — читает `/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db` напрямую и точно восстанавливает существующие папки, позиции и страницы
- **Классический опыт постраничной сетки** — поиск, навигация с клавиатуры, перетаскивание для изменения порядка, создание папки перетаскиванием одного значка на другой
- **Рендеринг полностью на Core Animation**, включая перетаскивание прямо в Dock и нативные значки папок Liquid Glass на macOS 26
- **Режимы раскладки папок**: постраничный (как в оригинале) или с вертикальной прокруткой — на выбор
- **Нечёткий поиск** с поддержкой транслитерации CJK (пиньинь и др.), так что даже неточный или частичный ввод находит нужное приложение
- **Активация через hot corner и жесты трекпада**, включая экспериментальную поддержку pinch/tap четырьмя и пятью пальцами
- **CLI и TUI** для просмотра и управления раскладкой из терминала
- **Подписанные автоматические обновления** через [Sparkle](https://sparkle-project.org) — обычная кнопка «Проверить обновления» прямо в приложении
- **Локальные бэкапы** в выбранную вами папку, с управляемой историей, из которой можно восстановиться
- **Скрытие подписей иконок, изменение размера значков и отступов** — отдельно для главной сетки и для содержимого папок
- **13 языков** с полным переводом интерфейса (см. список языков выше)
- **Улучшенные контекстные меню** — показать в Finder, скопировать путь к приложению, переименовать папку и (по желанию) снятие карантина Gatekeeper для других доверенных приложений
- **Поддержка контроллера и голосовой обратной связи** для доступности

## Что забрала macOS Tahoe

- Нет пользовательских папок и произвольной организации
- Нет перетаскивания для изменения порядка
- Нет вообще никакого визуального управления приложениями — только автоматически сгенерированная сетка по алфавиту, которую нельзя трогать

LaunchNG существует потому, что это реальный шаг назад, а не разумное решение по умолчанию.

## Где хранятся данные

Собственная раскладка, настройки и кэш LaunchNG хранятся здесь:

```
~/Library/Application Support/LaunchNG/Data.store
```

Никакие данные никуда не отправляются. Единственная сетевая активность — проверка фида обновлений и, если вы сами это запустите, чтение системной базы Launchpad по пути:

```bash
/private$(getconf DARWIN_USER_DIR)com.apple.dock.launchpad/db/db
```

## Установка

### Требования

- macOS 26 (Tahoe) или новее
- Apple Silicon или Intel
- Xcode 26, если собираете из исходников

### Сборка из исходников

```bash
git clone https://github.com/moonmig/LaunchNG.git
cd LaunchNG
open LaunchNG.xcodeproj
```

<a name="configure-local-code-signing"></a>**Настройка локальной подписи** (платный аккаунт разработчика Apple не требуется):

- Выберите таргет **LaunchNG** → **Signing & Capabilities** → установите **Team** в `None`, сертификат — `Sign to Run Locally`. Hardened Runtime оставьте включённым.
- После этого Xcode пометит файл проекта как изменённый — не включайте изменения, связанные только с подписью, в pull request.

Чтобы запустить через `⌘R`, назначением должен быть **My Mac** — универсальное назначение/«Any Mac» может собрать и заархивировать приложение, но не запустит его для отладки. `⌘B` — только сборка.

### Сборка из командной строки

```bash
xcodebuild -project LaunchNG.xcodeproj -scheme LaunchNG -configuration Release

# Универсальный бинарник (Apple Silicon + Intel):
xcodebuild -project LaunchNG.xcodeproj -scheme LaunchNG -configuration Release \
  ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO clean build
```

## Как пользоваться

1. **При первом запуске** приложение автоматически сканирует установленные программы.
2. **Настройки → General → Import System Launchpad** — импортирует вашу текущую раскладку, папки и позиции в один клик.
3. Клик — выбрать, двойной клик (или Return) — запустить; начните печатать где угодно, чтобы искать.
4. Перетащите одно приложение на другое, чтобы создать папку; перетаскивайте приложения, чтобы менять порядок.
5. При желании включите CLI в Настройках, если хотите управлять раскладкой из терминала.

### Полноэкранный режим и компактный

- **Полноэкранный** занимает весь экран — ближе всего к оригинальному Launchpad.
- **Компактный** — плавающее окно со скруглёнными углами, которое можно менять в размере.
- Настройки внешнего вида (масштаб иконок, отступы, положение индикатора страниц и др.) хранятся отдельно для каждого режима.
- В полноэкранном режиме можно опционально скрыть строку меню; Dock при этом macOS скрывает автоматически.

## Заметные настройки

- **Внешний вид**: масштаб иконок, размер и видимость подписей, отступы сетки — отдельные значения для содержимого папок — плюс стиль фона (размытие, нативное Liquid Glass или фон на основе живых обоев)
- **Поиск**: переключатель нечёткого поиска и задержка debounce
- **Скрытые приложения**: убрать конкретные приложения из сетки, не удаляя их
- **Бэкап**: выберите папку, создавайте бэкапы с меткой времени, восстанавливайте или удаляйте старые из списка
- **Горячие клавиши и жесты**: глобальная горячая клавиша, hot corner и (экспериментальные) привязки жестов трекпада
- **Обновления**: переключатель автопроверки и кнопка ручной проверки — оба на базе Sparkle

## Решение проблем

**Приложение не запускается.** Убедитесь, что у вас macOS 26.0 или новее, и что флаг карантина снят (см. выше).

**«Проверить обновления» сообщает об ошибке.** LaunchNG использует Sparkle с подписанным фидом обновлений; ручная проверка всегда должна отражать последний опубликованный релиз в течение нескольких минут.

**Нет команды `launchng` в терминале.** Она включается по желанию — сначала включите интерфейс командной строки в Настройках, и LaunchNG сам установит (а позже сможет удалить) управляемую команду.

## Вклад в проект

1. Сделайте fork репозитория
2. Создайте ветку для своей фичи (`git checkout -b feature/your-feature`)
3. Закоммитьте изменения с понятным описанием
4. Запушьте ветку и откройте pull request

Что поможет ревью пройти быстрее:
- Не включайте в diff изменения Xcode-проекта, связанные только с подписью (см. раздел про локальную подпись выше)
- Если трогаете сетку на Core Animation, сначала загляните в `GridReorderPlan.swift` — логика переупорядочивания/страниц должна жить там, а не дублироваться по разным вью
- Прогоните тесты перед открытием PR:
  ```bash
  xcodebuild test -scheme LaunchNG -destination 'platform=macOS'
  ```

Свежие актуальные скриншоты (главная сетка, пара вкладок настроек) — тоже полезный вклад, см. плейсхолдер в начале файла.
